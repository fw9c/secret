# Uwuifier for Discord in a browser (no APK, no Vencord)

A userscript that uwuifies messages as they're sent to Discord. Works on a
phone with stuff straight from the Play Store.

## Phone setup

1. Install **Firefox** from the Play Store.
2. In Firefox: menu → Extensions → find **Violentmonkey** → Add.
3. Open this link in Firefox and tap **Install** when Violentmonkey asks:
   `https://raw.githubusercontent.com/fw9c/secret/main/browser/uwuifier.user.js`
   (the repo has to be public for that link to work)
4. Go to `discord.com/app` and log in. If it keeps nagging you to get the app,
   turn on "Desktop site" in the Firefox menu.

The pink **uwu** tab on the right edge turns it on and off (faded and crossed
out = off). On a keyboard, Ctrl+Shift+U does the same.

To change swear mode / stutter / faces, edit the settings at the top of the
script in Violentmonkey.

## Limits

It's Discord's website, not the app: no push notifications, voice is meh.
